# Impeccable — Project Design Context

## Design Context

### Users
- **Space-soundtrackers:** coffee shop and vintage store owners matching music to the scent/atmosphere of their space (candle on the counter, beans on the shelf). Often on a phone behind a counter; zero patience for logins.
- **Vibe-soundtrackers:** students and anyone setting a mood for a session (afternoon self-study, group study). Arrive with a feeling, not a product.
- **Recipients:** strangers opening a shared `/score/<slug>` URL. They must understand the product from the score page alone — for most visitors the score page IS the first impression.
- Job to be done: turn scent language (fragrance notes, candle labels, coffee tasting notes, free prose) into a structured, reasoned, playable playlist in under 30 seconds, no account.

### Brand Personality
- **"An unusually perceptive record-store employee."** Perceptive, warm, curatorial. Explains *why* each track belongs, never just lists.
- Voice is lowercase, literate, sensory. Writes tasting notes, not marketing copy. Never hypey, never corporate, never "AI-powered ✨."
- Emotional target: the small delight of being *understood* — "how did it know cedar sounds like this?"

### Aesthetic Direction

*(Revised 2026-07-27, builder direction. Supersedes the "liner notes from an apothecary" warm system — the warm cream/citrine/terracotta cast colored every score identically regardless of the scent's character. Copy anchors, the type system, and the drydown scroll survive; the palette does not.)*

- **"Gallery in morning fog"** — neutral, minimal, editorial. Near-white space, hairline rules, desaturated gray-green tonal accents, generous whitespace. Reference feel: a soft-white photo gallery where muted imagery floats in space (the halo-carousel demo the builder pointed to). The page is a quiet room; **the music's own album artwork is the only color in it.**
- **Two themes, both v1.** A visible light/dark toggle in the header; default follows `prefers-color-scheme`; choice persists in `localStorage`. Everything below is expressed as CSS custom properties — no hardcoded colors in component styles.
  - **Light "mist":** background `#FAFAF7`, raised surface `#F2F2EE`, ink `#1C1C1A`, secondary text `#6B6B64`, hairlines `#E3E3DD`.
  - **Dark "slate":** background `#161614`, raised surface `#1E1E1C`, text `#E6E6E1`, secondary `#9A9A92`, hairlines `#2A2A27`. Never pure black/white in either theme.
  - **Interactive/link:** sage-slate `#4A5250` light / `#A9B3AE` dark. Indie-find badge: outline in the link color, no fill.
- **Phase accents — the drydown is depth, not hue:** top "vapor" `#A8ADA6` → heart "stone" `#70756E` → base "char" `#3A3E38` (light theme). Dark theme runs the other way — `#6E736C` → `#9AA097` → `#D2D6CE` — the scent emerging from the dark. Tone deepens as the scent settles; no warm/cool hue journey.
- **Color from artwork only.** The 3D album-art halo carousel at the top of the score page is where color lives; UI chrome never competes with it. No gradients anywhere except the arc visualization's tonal ramp.
- **Typography (unchanged):** Fraunces (variable, SOFT axis up) for score titles, wordmark, phase headers; Newsreader 17–18px/1.6 for interpretation prose; IBM Plex Mono 13px for track metadata and sensory justifications (each reads like a typed tasting note — never set justifications in the display face).
- **Wordmark:** `vibin' out` — lowercase, Fraunces, purely typographic, generous letter-spacing, no icon. The apostrophe is the single accent (sage-slate, was citrine); everything else ink/text color. Clean slate from the 2022 design; nothing else survives.
- **Layout:** single 640px column, 8px spacing unit, 96px between fragrance phases, 24px between tracks, 4px between a track and its justification (they are one thought). The input card gets 48px internal padding and sits alone on the page.
- **Signature interaction (the only big one):** the drydown scroll — as the score page scrolls from top notes to base notes, phase headers, the arc's highlighted segment, and accents deepen vapor → stone → char (scroll-linked CSS; reduced-motion users get a simple crossfade). Second permitted motion: the halo carousel's slow rotation (reduced-motion: static fanned row). Everything else near-zero: 150ms ease-out on pills/buttons.
- **Copy anchors (adopted, unchanged):** headline "Describe what's in the air."; phase labels "The first impression / What takes over / What remains"; premise line "Top notes open the room. Heart notes give it feeling. Base notes decide what stays."
- **Anti-references:** the retired warm-apothecary cast (cream/citrine/terracotta — do not drift back); generic AI-tool aesthetics (neon/cyan accents, purple-blue gradients, glassmorphism, gradient text); Spotify-clone dark UI (our dark theme is warm-gray editorial, not #121212 + green); identical card grids; the project's own 2022 look (default Montserrat, cornflowerblue header, gray `#eee` wrapper, unrelated mint/gold/lavender accents).

### Design Principles
1. **Fog, not product.** Tinted neutrals, no pure black/white, no dark-neon, no warm cast. If a screen could pass for a SaaS dashboard — or a coffee-bag label — it's wrong. It should feel like a quiet gallery.
2. **The type is the brand.** Three faces, three fixed roles (Fraunces = display, Newsreader = prose, Plex Mono = tasting notes). No icon logo, no decorative fonts beyond these.
3. **Color belongs to the music.** Album artwork (the halo carousel, embed thumbnails) is the only saturated color on any page. UI chrome stays tonal in both themes.
4. **Reasoning is the product.** Every track visibly carries its *why*. Layout and type must make the justifications feel authored, not generated — they get equal billing with the track.
5. **Two motions, no more.** The drydown scroll enacts the fragrance's evolution; the halo carousel turns slowly. Everything else stays still. Reduced-motion fallback always.
6. **Restraint is the first impression.** One CTA per screen, single column, no cards-in-cards, whitespace on purpose. The input page contains a textarea, an optional photo drop, two pill rows, one button — and nothing else.
7. **Meaning never rides on color alone.** Phase tones always pair with text labels; WCAG AA (contrast ≥ 4.5:1 in BOTH themes, visible focus states, full keyboard navigation) is the standing bar.
