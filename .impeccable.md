# Impeccable — Project Design Context

## Design Context

### Users
- **Space-soundtrackers:** coffee shop and vintage store owners matching music to the scent/atmosphere of their space (candle on the counter, beans on the shelf). Often on a phone behind a counter; zero patience for logins.
- **Vibe-soundtrackers:** students and anyone setting a mood for a session (afternoon self-study, group study). Arrive with a feeling, not a product.
- **Recipients:** strangers opening a shared `/score/<slug>` URL. They must understand the product from the score page alone — for most visitors the score page IS the first impression.
- Job to be done: turn scent language (fragrance notes, candle labels, coffee tasting notes, free prose) into a structured, reasoned, playable playlist in under 30 seconds, no account.

### Brand Personality
- **"An unusually perceptive record-store employee."** Perceptive, warm, curatorial. Explains *why* each track belongs, never just lists.
- Voice is lowercase, literate, sensory. Writes tasting notes, not marketing copy. Never hypey, never corporate, never "AI-powered ✨."
- Emotional target: the small delight of being *understood* — "how did it know cedar sounds like this?"

### Aesthetic Direction
- **"Liner notes from an apothecary"** — warm editorial print, ink on paper. The page should read like a perceptive clerk's typed card taped to a record sleeve. It should look like the objects the audience already trusts: coffee bags, candle labels, 33⅓ books.
- **Paper:** `#F6F1E7` (never pure white). **Ink:** `#211D17` (never pure black). Light theme; dark mode is not a v1 goal.
- **Phase accents (the drydown arc):** top = citrine `#D9A441`, heart = terracotta `#B8552F`, base = resin `#4A3B2A`. Interactive/link color: vetiver green `#3F5142`. Indie-find badge: vetiver outline, no fill. Gradients belong ONLY to the arc visualization, never to UI chrome or text.
- **Typography:** Fraunces (variable, SOFT axis up) for score titles, wordmark, and phase headers; Newsreader 17–18px/1.6 for interpretation prose; IBM Plex Mono 13px for track metadata and the one-line sensory justifications (each reads like a typed tasting note — never set justifications in the display face).
- **Wordmark:** `vibin' out` — lowercase, Fraunces, purely typographic, generous letter-spacing, no icon. The apostrophe is the single drop of color (citrine `#D9A441`); everything else ink. Clean slate from the 2022 design; nothing else survives.
- **Layout:** single 640px column, 8px spacing unit, 96px between fragrance phases, 24px between tracks, 4px between a track and its justification (they are one thought). The input card gets 48px internal padding and sits alone on the page.
- **Signature interaction (the only big one):** the drydown scroll — as the score page scrolls from top notes to base notes, phase headers, the arc's highlighted segment, and link accents shift citrine → terracotta → resin (scroll-linked CSS; reduced-motion users get a simple crossfade). Motion elsewhere is near-zero: 150ms ease-out on pills/buttons.
- **Copy anchors (adopted):** headline "Describe what's in the air."; phase labels "The first impression / What takes over / What remains"; premise line "Top notes open the room. Heart notes give it feeling. Base notes decide what stays."
- **Anti-references:** generic AI-tool aesthetics (dark mode + neon/cyan accents, purple-blue gradients, glassmorphism, gradient text); Spotify-clone dark UI; identical card grids; and the project's own 2022 look (default Montserrat, cornflowerblue header, gray `#eee` wrapper, unrelated mint/gold/lavender accents). The deliberately-considered-and-rejected alternative was a dark "after-hours record sleeve" direction — do not drift back toward it by default.

### Design Principles
1. **Paper, not product.** Warm cream and ink, tinted neutrals, no pure black/white, no dark-neon. If a screen could pass for a SaaS dashboard, it's wrong.
2. **The type is the brand.** Three faces, three fixed roles (Fraunces = display, Newsreader = prose, Plex Mono = tasting notes). No icon logo, no decorative fonts beyond these.
3. **Reasoning is the product.** Every track visibly carries its *why*. Layout and type must make the justifications feel authored, not generated — they get equal billing with the track.
4. **One signature motion.** The drydown scroll enacts the fragrance's evolution; everything else stays still. Reduced-motion fallback always.
5. **Restraint is the first impression.** One CTA per screen, single column, no cards-in-cards, whitespace on purpose. The input page contains a textarea, two pill rows, one button — and nothing else.
6. **Meaning never rides on color alone.** Phase colors always pair with text labels; WCAG AA (contrast ≥ 4.5:1, visible focus states, full keyboard navigation) is the standing bar.
